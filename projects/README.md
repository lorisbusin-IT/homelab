# 🎨 Eigene Projekte

## 🗺️ Weltmap
Interaktive Weltkarte mit Leaflet.js und OpenStreetMap.
- Orte markieren (Besucht/Wunschliste)
- Notizen zu jedem Ort
- Statistiken
- Daten im localStorage

## 📰 News Aggregator
Schweizer News Aggregator mit Flask.
- Quellen: Tagesanzeiger + SRF
- Artikel-Volltext
- SQLite Datenbank
- Archiv Funktion

## 🔍 NetSpy
Netzwerk Scanner Dashboard mit Flask und Nmap.
- Geräte kategorisieren und umbenennen
- Favoriten und Notizen
- Netzwerk-Karte
- Pi-hole DNS Log Integration
- REST API

## 🎮 Spiele-Plattform
17 Browser-Spiele mit Nginx.
- Snake, Tetris, Pac-Man, Space Invaders, Pong
- Minesweeper, Memory, 2048, Wordle, Sudoku
- Hangman, Dino Runner, Asteroids, Quiz
- Endless Runner, Aim Trainer, Simon Says
- Highscores, Partikel-Effekte, Press Start 2P Font

## 🎵 BeatLab Studio
Online DAW mit Flask Backend.
- Drum Sequencer (9 Spuren)
- Piano mit Oktaven und Wellenformen
- Gitarre mit Akkorden
- Mixer mit FX (Hall, Echo, Bass, Höhen, Speed, Pitch)
- Beats speichern und laden

## 🖥️ eDEX-UI
Terminal Dashboard inspiriert von eDEX-UI.
- Echte Proxmox API Daten
- Terminal mit echten Befehlen
- Verschiedene Themes
- Easter Eggs
- Ping Monitor, Notes, CT Stats
