# 🏠 Homelab

Mein persönliches Homelab auf einem Proxmox VE Server.

## 🖥️ Hardware

| Komponente | Details |
|------------|---------|
| Gerät | Lenovo ThinkCentre M720q Tiny |
| CPU | Intel i5-8400T (6 Kerne) |
| RAM | 16GB |
| SSD | 256GB |
| OS | Proxmox VE 9.2.3 |

## 🌐 Netzwerk

- Router: Swisscom Internet-Box 5
- DNS: Pi-hole
- VPN: WireGuard
- DDNS: DuckDNS
