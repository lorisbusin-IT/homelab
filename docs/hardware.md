# 🖥️ Hardware

## Server: Lenovo ThinkCentre M720q Tiny

### Warum der M720q?
- ✅ Klein (nur 1.5L Volumen)
- ✅ Leise (kaum hörbar)
- ✅ Stromsparend (~15W idle, ~35W unter Last)
- ✅ Günstig (~150-200 CHF gebraucht)
- ✅ Intel i5-8400T mit 6 Kernen reicht für viele Container
- ✅ Unterstützt bis 32GB RAM
- ✅ M.2 NVMe Slot vorhanden

### Spezifikationen
| Komponente | Details |
|------------|---------|
| CPU | Intel i5-8400T (6C/6T, 1.7-3.3GHz, 35W TDP) |
| RAM | 16GB DDR4-2666 (2x 8GB SO-DIMM) |
| Storage | 256GB SSD |
| Netzwerk | Intel I219-LM Gigabit |
| USB | 4x USB 3.1, 2x USB 2.0 |
| Display | 1x DisplayPort, 1x HDMI |

### Upgrade Möglichkeiten
- RAM: Bis 32GB (2x 16GB SO-DIMM)
- Storage: M.2 NVMe SSD empfohlen
- USB NIC für separates Netzwerk möglich
